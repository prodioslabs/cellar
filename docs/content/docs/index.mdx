title: Introduction
description: Control plane for isolated microsandbox VMs
---

Cellar is a control plane for isolated [microsandbox](https://github.com/superradcompany/microsandbox) VMs.
This project implements the **cluster identity layer** (mTLS gRPC, Raft-replicated CA) and
**sandbox lifecycle** (desired state in Raft, local microsandbox driver on every node).

Clients use the **official microsandbox SDKs** in cloud mode with the backend URL set to
**`cellar-gateway`**. See [Client API](/docs/api).
