title: Introduction
description: Run microsandboxes on your own cloud today
---

Cellar helps you run [microsandbox](https://github.com/superradcompany/microsandbox) on your own cloud today. Put it on a laptop, a rack, or VMs on AWS or GCP, and you get the same isolated environments a hosted product would give you — without waiting on someone else's cloud.

Each sandbox is a real virtual machine, not a container sharing the host kernel. That is the point: untrusted code stays boxed in, whether you are evaluating a model, running a user-submitted script, or spinning up a short-lived workspace.

You install Cellar, start a cluster, and add more machines when you need capacity. From there you can create sandboxes with the CLI, or from your own apps using the **official microsandbox SDKs**. Point the SDK at your Cellar gateway, pass an API key, and you are talking to sandboxes you run yourself. There is no separate Cellar SDK.

The rest of these docs walk through install, joining nodes, and connecting clients.
