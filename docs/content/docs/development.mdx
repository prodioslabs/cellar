---
title: Development
description: Proto generation and tests
---

```bash
make tools   # install protoc-gen-go and protoc-gen-go-grpc (needs protoc on PATH)
make proto   # regenerate gRPC stubs under api/gen/
make build   # cellard (CGO_ENABLED=1), cellar, cellar-gateway
make test
make clean
```

`cellard` needs CGO because the microsandbox Go SDK dlopens FFI libraries.
